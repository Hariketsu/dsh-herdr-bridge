Each DSH session you run becomes an hc terminal in Herdr. Herdr App shows its status, Herdr agents can read and drive it with `hc`, and approvals can be answered here or in Herdr; the first answer wins.

To choose where sessions show in Herdr App, open the **Herdr Bridge** component below.

There's nothing else to set up. More in the [full guide](https://github.com/Hariketsu/dsh-herdr-bridge#readme).
